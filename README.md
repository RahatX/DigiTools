# DigiTools Platform
DigiTools Platform is a modern digital tools buying website where users can explore premium tools, add products to the cart, remove selected items, and complete checkout through a clean and responsive interface.

## Live Project Features
- Users can browse premium digital tools in a responsive product grid.
- Users can add products to the cart and see the cart count update instantly.
- Users can remove selected items from the cart and clear all products through the checkout button.

## Technologies Used
- HTML5
- React.js
- Tailwind CSS
- JavaScript (ES6+)
- React-Toastify (NPM Package)
- JSON (for product data)

## Sections Included
- Sticky Navbar
- Hero Section
- Stats Section
- Products Section
- Cart Section
- Steps Section
- Pricing Section
- CTA Section
- Responsive Footer

## Cart Functionalities
- Add to cart
- Prevent duplicate product selection
- Remove from cart
- Show total price
- Proceed to checkout
- Empty cart state message

## Responsive Design
The website is fully responsive for mobile, tablet, and desktop devices. Special attention was given to the footer, cart section, grid layout, and mobile navigation menu so the design remains organized on smaller screens.

## Project Purpose
The purpose of this project is to build a visually appealing digital tools marketplace that combines a modern SaaS-style interface with useful cart interactions and responsive design principles.
